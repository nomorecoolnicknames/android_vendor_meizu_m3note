# Meizu M3 Note (M681 / L681) vendor blobs

Board profiles for the Meizu M3 Note (M681 and L681, MT6755), LineageOS 16.0.

Used by [android_device_meizu_m3note](https://github.com/nomorecoolnicknames/android_device_meizu_m3note) (`lineage-16.0`)
together with [android_vendor_meizu_m681](https://github.com/nomorecoolnicknames/android_vendor_meizu_m681), which
both boards run. `proprietary/l681` holds the L681 files (stock Flyme 6.3.0.0G, Android 5.1) that are bind-mounted
over the M681 ones on the L681.

The files are property of Meizu and MediaTek and keep their original terms.
